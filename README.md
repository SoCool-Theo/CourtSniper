# Folder Architecture

## courtsniper

```
courtsniper/
│
├── config.py             # Stores booking targets, URL, and execution timestamps
├── setup_session.py      # One-time script to log in manually and save browser cookies
├── sniper.py             # Precision engine that polls the OS clock and fires the message
└── user_data/            # Local directory generated by Playwright to store persistent sessions
```
